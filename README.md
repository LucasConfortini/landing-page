## Como visualizar

Não é necessário instalar dependências.

1. Abra a pasta do projeto.
2. Dê dois cliques em `index.html`.
3. A página abre no navegador padrão.

Para um servidor local (opcional):

```bash
npx --yes serve .
```

Para simular o celular no Chrome ou no Edge: `F12`, depois `Ctrl + Shift + M`.
